## Назначение

Программа распознаёт десять видов персональных данных в русскоязычном тексте:

| Класс | Атрибут |
| --- | --- |
| `SURNAME` | Фамилия |
| `NAME` | Имя |
| `INN` | ИНН |
| `PASSPORT` | Серия и номер паспорта |
| `CARD` | Номер банковской карты |
| `SNILS` | СНИЛС |
| `URL` | URL |
| `PHONE` | Номер телефона |
| `MARRIAGE_CERT` | Серия и номер свидетельства о браке |
| `CADASTRAL` | Кадастровый номер |

Структурированные атрибуты выделяются регулярными выражениями и проверяются с учётом контекста. Для ИНН, СНИЛС и банковских карт применяются контрольные алгоритмы. Имена и фамилии обрабатываются по контексту и словарю падежных форм. При обезличивании значения заменяются искусственно созданными значениями того же типа. Повторные упоминания в пределах одного сеанса получают согласованные замены.

## Запуск

Для базового распознавания и измерения F1 достаточно Python 3.10 или новее. Внешние библиотеки не требуются.

```bash
python pdn.py "Гражданин Иванов Пётр. Телефон: +7 (916) 123-45-67."
python make_dataset.py
python evaluate.py
python -m unittest -v test_pdn.py
```

Программный интерфейс:

```python
from pdn import Anonymizer, anon, recognize

text = "Заявитель: Иванов Иван."
entities = recognize(text)
changed, positions = anon(text, seed=15)

session = Anonymizer(seed=15)
first, _ = session.anonymize(text)
second, _ = session.anonymize(first)
assert first == second
```

Позиции сущностей указываются как `[LABEL, start, end]` в исходной строке. Идемпотентность обеспечивается при повторном вызове в рамках **одного экземпляра `Anonymizer`**; новый экземпляр создаёт новые псевдонимы.

## Корпус и результаты

Файл `data/test.jsonl` содержит **150 синтетических текстов** с **1 050 эталонными упоминаниями**. Все десять типов имеют не менее 93 размеченных упоминаний. Эталонные смещения создаются при формировании текста, а не по ответам распознавателя. BIO-разметка записана в `data/test_bio.jsonl`.

На данном наборе получены следующие показатели:

| Метрика | Значение |
| --- | ---: |
| Средневзвешенная F1 без `O` | 1,000 |
| Макро-F1 без `O` | 1,000 |
| Средневзвешенная BIO-F1 без `O` | 1,000 |
| Автоматические тесты | 15/15 |

Подробные показатели каждого класса находятся в `results/recognition_metrics.json`. Значения относятся исключительно к синтетическим текстам, близким к шаблонам генерации; это не оценка качества на независимом наборе реальных документов.

## Оценка сохранения семантики

Скрипт `evaluate.py` формирует три сопоставимых варианта текста: синонимическое обезличивание, маскирование обнаруженных сущностей звёздочками и полное маскирование. Вспомогательные показатели посимвольного сходства рассчитываются без дополнительных библиотек.

Для расчёта **BERTScore на RuBERT**:

```bash
python -m pip install -r requirements-bertscore.txt
python evaluate.py --bertscore --model DeepPavlov/rubert-base-cased
```

Численные значения после фактического запуска записываются в `results/bertscore_metrics.json`. Без этого файла BERTScore считается невыполненным; посимвольное сходство не является заменой BERTScore. Для запуска без локальной установки модели предусмотрен `run_bertscore_in_colab.ipynb`; автоматизация также описана в `.github/workflows/bertscore.yml`.

## Ограничения

Решение представляет учебный прототип. Словарь имён ограничен, часть реквизитов обнаруживается только с явным указанием поля, сложная морфология и косвенные идентификаторы не охватываются. Сохраняемые префиксы реквизитов могут нести чувствительную информацию. Для работы с настоящими персональными данными необходимы независимая оценка качества и анализ риска повторной идентификации.
