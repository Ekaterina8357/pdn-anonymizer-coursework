# Курсовая работа — распознавание и синонимическое обезличивание ПДн

## Что включено

- `docs/Курсовая_ПДн_ГОСТ_7.32_2017.docx` - отчет
- `pdn.py` - автономное распознавание 15 типов ПДн, синонимическая замена, валидация, BIO-разметка, CLI.
- `make_dataset.py` - генерация 300 синтетических размеченных текстов, 150 на каждый вариант.
- `data/test.jsonl` - 300 синтетических текстов, 2100 независимо заданных эталонных упоминаний.
- `data/test_bio.jsonl` - по-токеновая BIO-разметка.
- `evaluate.py` - полная оценка F1 и подготовка сравнений; опциональный реальный расчёт BERTScore.
- `results/recognition_metrics.json` - воспроизводимые измерения качества.
- `results/anonymized_comparison.jsonl` - 300 троек исходный / синонимический / маскированный.
- `test_pdn.py` - модульные тесты (15 штук).
- `ЗАГРУЗКА_НА_GITHUB_И_СДАЧА.md` - пошаговая инструкция для первого размещения репозитория и сдачи преподавателю.
- `run_bertscore_in_colab.ipynb` - дополнительный ноутбук для BERTScore на Google Colab.

### Требования

- Python версии 3.10 и выше (проверено на Python 3.12.14 и 3.13.5).
- Базовая программа (`pdn.py`, `make_dataset.py`, `evaluate.py` без `--bertscore`, тесты)
- `requirements.txt` содержит необязательные `pymorphy3` и `Faker` для возможных расширений. Для формирования предложений используется встроенный словарь из `pdn.py`.
- Для BERTScore нужно установить `requirements-bertscore.txt` и иметь доступ к предварительно обученной русскоязычной модели.

### Быстрый запуск

Откройте терминал **в каталоге проекта** и выполните:

```bash
python make_dataset.py
python evaluate.py
python -m unittest -v test_pdn.py
```

Ожидаемый итог на синтетических текстах:

- 300 текстов и 2100 сущностей;
- средневзвешенная F1 (без O) — **1.000**;
- средняя F1 (без O) — **1.000**;
- средневзвешенная BIO F1 (без O) — **1.000**;
- 15 пройденных модульных тестов.

**Эти результаты получены на синтетических шаблонных текстах и не означают, что распознаватель имеет F1=1 на реальных документах.**

### Программный интерфейс

```python
from pdn import anon, Anonymizer, recognize, bio_tags

s = 'Гражданин Иванов Пётр. ИНН: 7701291417.'
changed, attrs = anon(s, variant='odd', seed=11)
print(changed)
print(attrs)  # [["SURNAME", start, end], ["NAME", start, end], ...]

# Внутри одного сеанса отображения согласованы и повторное
# обезличивание результата не изменяет текст:
a = Anonymizer('odd')
changed1, _ = a.anonymize(s)
changed2, _ = a.anonymize(changed1)
assert changed1 == changed2
```

Через CLI:

```bash
python pdn.py "Заявитель: Иванов Антон. E-mail: anton@example.ru." --variant even
python pdn.py "Гражданин Иванов Пётр. ИНН: 7701291417." --variant odd
```

Варианты: `odd` — нечётный, `even` — чётный, `all` — оба набора одновременно.

### BERTScore — обязательный дополнительный запуск

Этот шаг реализован **настоящей метрикой BERTScore**, не суррогатом. Для него требуются интернет при первом скачивании весов и свободное дисковое пространство. После установки выполните:

```bash
python -m pip install -r requirements-bertscore.txt
python evaluate.py --bertscore --model DeepPavlov/rubert-base-cased
```

По завершении появится `results/bertscore_metrics.json` с `synonym.f1`, `mask.f1`, `full_mask.f1`, `delta_f1` и другими параметрами. `mask` скрывает только сущности ПДн, `full_mask` заменяет звёздочками весь текст. Если библиотека или веса не скачиваются, команда выдаст исключение. Наличие файла `results/bertscore_metrics.json` со статусом `computed` подтверждает выполненный расчёт, а не его план.

### Автоматический эксперимент на GitHub

Файл `.github/workflows/bertscore.yml` запускает тесты, настоящий BERTScore, обновляет отчёт и сохраняет результаты после первой загрузки кода в ветку `main`. Статус см. на вкладке **Actions** в репозитории. При успешном выполнении значения BERTScore появятся в `results/bertscore_metrics.json`, а в папке `docs` — обновлённые Word и PDF с числовыми значениями и выводами. Если запуск не начался автоматически, выберите workflow **Calculate BERTScore and update coursework report → Run workflow**. Нужен включённый GitHub Actions с доступом к установке библиотек и весам модели.

Удобнее всего воспользоваться `run_bertscore_in_colab.ipynb`: загрузите zip архива в Colab и выполняйте клетки по порядку. Файл результата можно затем включить в раздел 5 отчёта, заполнив его таблицу реальными числами.

### Состав корпуса

Синтетический набор создан самостоятельно. Использование внешнего factRuEval-2016 рекомендовано в задании, но допускается самостоятельно сформированный корпус; **исходный factRuEval в проект не включён**. Это важно учитывать при устной защите.

### Оговорки о качестве и безопасности

Алгоритм — учебный прототип: контекстные правила и ограниченный морфологический словарь не гарантируют обнаружение всех ПДн. Сгенерированные цифры могут совпасть с реально существующими реквизитами случайно; использовать их как действующие документы нельзя. Код не даёт гарантий необратимой анонимизации и не должен без доработки обрабатывать чувствительные документы.
