# Как разместить курсовую на GitHub и сдать её до 20 ноября 2026 года

Это инструкция для человека, который не писал программу самостоятельно и впервые загружает проект. Пользоваться Git-командами **необязательно**.

## Шаг 1. Подготовьте файлы

1. Скачайте архив `Курсовая_ПДн_Python_полный_проект.zip`.
2. Нажмите по архиву правой кнопкой мыши → «Извлечь всё».
3. Откройте извлечённую папку `coursework_pdn`.
4. В ней должны быть `pdn.py`, `evaluate.py`, `make_dataset.py`, `test_pdn.py`, папки `data`, `docs`, `results`, а также `README.md`.

Не загружайте только архив как единственный файл в репозиторий: тогда преподавателю неудобно смотреть исходный код. Лучше выложить **содержимое папки `coursework_pdn`** с вложенными папками.

## Шаг 2. Создайте репозиторий

1. Войдите на [github.com](https://github.com/) под своим аккаунтом.
2. Нажмите значок `+` в правом верхнем углу → **New repository** (или откройте [github.com/new](https://github.com/new)).
3. Название репозитория: `pdn-anonymizer-coursework` (можно выбрать другое).
4. В поле Description, если хочется, напишите: `Курсовая работа на Python: распознавание и синонимическое обезличивание персональных данных`.
5. **Public**: преподаватель сможет открыть ссылку без приглашения. В проекте использованы синтетические данные, однако публичность означает, что **код и отчёт увидит любой человек по ссылке и при поиске**. Если не хотите этого, выберите **Private**, а преподавателю отправьте архив или пригласите его в репозиторий.
6. Нажмите **Create repository**. Не включайте создание нового README, если собираетесь загрузить готовый README из комплекта.

## Шаг 3. Загрузите исходники без командной строки

1. На странице пустого репозитория найдите ссылку **uploading an existing file** (или кнопку **Add file → Upload files**).
2. В проводнике Windows откройте `coursework_pdn`. Выделите файлы и папки **внутри неё**, а не саму внешнюю папку.
3. Перетащите их в поле загрузки GitHub. Убедитесь, что сохранились папки `data`, `results`, `docs` и рядом видны `.py`-файлы.
4. В поле Commit message укажите `Add Python coursework project`.
5. Нажмите **Commit changes**. Дождитесь возвращения на главную страницу репозитория и убедитесь, что видны `pdn.py`, `README.md` и папки.
6. Скопируйте адрес страницы репозитория: `https://github.com/ВАШ_ЛОГИН/pdn-anonymizer-coursework` — **это только шаблон**; копировать нужно настоящий адрес из браузера.

Если загрузка целых папок браузером не сработала, удобная альтернатива — GitHub Desktop или запуск команд Git. Но для самой сдачи преподаватель прямо разрешил приложить готовый ZIP-архив вместо ссылки.

## Шаг 4. Что отправить преподавателю

До **20.11.2026 включительно** отправьте:

- отчёт `Курсовая_работа_ПДн_ГОСТ_7.32.docx` (или PDF, если принимается);
- **либо** ссылку на GitHub, **либо** архив проекта ZIP;
- если выполняете КМ-3 полностью — результаты реального BERTScore и выводы по ним в разделе 5 отчёта.

В актуальной версии проекта **метрики F1 посчитаны**, а BERTScore подготовлен к запуску, но ещё не вычислен из-за недоступности нейросетевых весов в текущем окружении. Не выдавайте посимвольное сходство за BERTScore.

## Шаг 5. Как запустить и получить BERTScore через Google Colab

1. Откройте [colab.research.google.com](https://colab.research.google.com/) и войдите в Google-аккаунт.
2. Выберите **Файл → Загрузить блокнот** и укажите `run_bertscore_in_colab.ipynb` из папки проекта.
3. В меню **Среда выполнения → Сменить среду выполнения** при возможности выберите GPU (необязательно).
4. Выполняйте блоки по порядку. После первого блока будет установлена библиотека `bert-score`, после второго Colab попросит загрузить ZIP-архив курсача.
5. Запустите следующий блок: он вычислит BERTScore между оригиналами и тремя версиями: синонимические замены, маскирование ПДн, полное маскирование.
6. Скачайте `bertscore_metrics.json`. В нём ключи `synonym.f1`, `mask.f1`, `full_mask.f1`, `delta_f1` и `delta_f1_full_mask`.
7. Сверьте модель и количество сравниваемых текстов; вставьте реальные значения в таблицу 6 отчёта и перепишите выводы раздела 5. Можно прислать этот JSON в ChatGPT вместе с Word-файлом — тогда отчёт будет дополнен точными показателями.

Если установка или скачивание модели не работает, покажите текст ошибки: по нему можно определить причину. Не заменяйте требуемый расчёт случайными числами.

## Как объяснить преподавателю программу своими словами

**Что делает?** Находит персональные данные в русском тексте и заменяет похожими по типу искусственными значениями.

**Почему регулярные выражения?** У реквизитов вроде ИНН и номера карты есть известные форматы, а для проверки правильности добавлены контрольные суммы.

**Как находят имена?** Используются слова-маркеры («гражданин», «заявитель»), словарь русских имён и фамилий, а также словарный проход для самостоятельных имён без явной подписи.

**Как сохраняют грамматику?** По форме имени или фамилии определяются род и падеж; новое имя склоняется аналогично. Для «Саша» род можно определить по словам «гражданин» и «гражданка» и по соседней фамилии.

**Что такое идемпотентность?** В рамках одного объекта-сессии одна исходная сущность имеет одну согласованную замену; повторно обезличенный текст не меняется. При новом сеансе замены могут быть иными.

**Откуда F1=1,0?** На 300 синтетических шаблонных текстах распознаватель не допустил ошибок. Это **не** означает, что на любой реальной переписке точность будет такой же. Для внешней оценки нужен отдельный независимый корпус.

**Что такое BERTScore?** Семантическая метрика на основе контекстных векторов нейросети, показывающая, насколько смысл изменился после синонимической замены или маскирования.

**Что такое основные файлы?**

| Файл | Простое объяснение |
| --- | --- |
| `pdn.py` | Алгоритм распознавания, проверки и обезличивания |
| `make_dataset.py` | Создание тестовых текстов и разметки |
| `evaluate.py` | Расчёт F1 и BERTScore |
| `test_pdn.py` | Автоматические проверки программы |
| `data/test.jsonl` | Тексты с правильными ответами |
| `results/recognition_metrics.json` | Измеренные показатели F1 |
| `docs/Курсовая_ПДн_ГОСТ_7.32_2017.docx` | Отчёт по ГОСТ |
